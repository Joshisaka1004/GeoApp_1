# GeoApp_1: GeoRätsel natural zur Gegenprüfung

16 neue Geometrie-Rätsel (GR 01–16, je Aufgabe und Lösungsbild auf Deutsch und Englisch), entstanden am 01.11.2026 für die App „Knobelwerk“.

## Inhalt
- `GeoRaetsel_natural/GR_nn_DE.png`, `_EN.png`: Aufgabenbilder
- `GeoRaetsel_natural/GR_nn_Loesung_DE.png`, `_EN.png`: Lösungsbilder
- `GeoRaetsel_natural/loesungen.md`, `solutions_en.md`: Lösungswege
- `GeoRaetsel_natural/Archiv_natural.md`: Antwort, Kniff, Schwierigkeit und bisherige Prüfung je Rätsel
- `GeoRaetsel_natural/skripte/`, `Werkzeug_natural/`: Zeichen- und Prüfskripte

## Bitte prüfen
1. Stimmt jede Antwort? Bitte unabhängig nachrechnen, nicht den Lösungsweg nur nachlesen.
2. Ist jede Aufgabe eindeutig? Fehlt eine Angabe, gibt es eine zweite Lösung (Archiv: GR 14 hatte rechnerisch zwei, siehe dort)?
3. Ist jede Zeichnung sauber und unmissverständlich: Beschriftung innerhalb des Winkels, nichts verdeckt, Lage und Berührung eindeutig, keine Linie, die wie die Lösung aussieht?
4. Passt der Aufgabentext zum Bild?
